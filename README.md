# 🎓 CDMP Preparation Repository

> **Studying in public. Building accountability. One chapter a day.**

A structured repository of daily study notes, chapter summaries, revision materials, and practical reflections for the **Certified Data Management Professional (CDMP) Fundamentals Exam**, based on the **DAMA-DMBOK2 Revised Edition**.

This repository serves as a personal knowledge base and long-term learning archive focused on mastering core data management principles through a practitioner-oriented lens.

> ⚠️ Note: This repository does not contain coding exercises or software implementations. The focus is on conceptual understanding, structured documentation, governance frameworks, and exam preparation.

---

# 📌 About the CDMP Exam

The **CDMP Fundamentals** exam is administered by **DAMA International** and validates knowledge across the DAMA-DMBOK2 framework.

| Detail | Information |
|--------|-------------|
| **Format** | 100 Multiple Choice Questions |
| **Duration** | 110 Minutes |
| **Pass Mark** | 60% (Associate), 70% (Practitioner), 80% (Master) |
| **Reference** | DAMA-DMBOK2 Revised Edition |
| **Mode** | Online Proctored |

> The exam is open book, but it heavily tests reasoning, interpretation, and practical application of data management concepts.
